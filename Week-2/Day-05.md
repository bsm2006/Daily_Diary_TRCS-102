## Topics Covered

### 1. Introduction to Feature Engineering

Feature engineering is the process of creating new features or transforming existing features to make a dataset more useful for analysis and machine learning.

The following types of feature engineering were covered:

- Date Features
- Mathematical Features
- Categorical Features
- Boolean/Flag Features
- Encoding Features

Pandas and NumPy were imported, and the sales dataset was loaded.

```python
import pandas as pd
import numpy as np

df = pd.read_excel("./DataSets/sales_data_messy.xlsx")
```

### 2. Datetime Feature Generation

Datetime features were generated by extracting useful information from the existing Date column. The `pd.to_datetime()` function was used to convert the Date column into datetime format.

The `.dt` accessor was used to extract different date-related components.

```python
df['Date'] = pd.to_datetime(df['Date'])

df['Order_Year'] = df['Date'].dt.year

df['Day_Name'] = df['Date'].dt.day_name()

df['Day_Number'] = df['Date'].dt.day_of_week

df['Day_of_Year'] = df['Date'].dt.day_of_year

df['Month'] = df['Date'].dt.month_name()

print(df[['Date', 'Order_Year', 'Month', 'Day_of_Year', 'Day_Name']].head(15))
```

Other datetime attributes studied included:

- `.dt.year` – Extracts the year.
- `.dt.month` – Extracts the month number.
- `.dt.month_name()` – Extracts the month name.
- `.dt.day` – Extracts the day of the month.
- `.dt.day_name()` – Extracts the weekday name.
- `.dt.week` – Accesses the week component.

### 3. Numerical Feature Generation

New numerical features were generated using existing columns such as Price, Quantity, and Revenue.

The calculations included total cost, cost per unit, profit, profit per unit, and profit margin.

**Cost Calculation**

The total cost was calculated by assuming that the cost of a product was 60% of its selling price.

```python
df['Cost'] = df['Price'] * df['Quantity'] * 0.60
```

**Cost Per Unit**

```python
df['Cost_per_Unit'] = df['Price'] * 0.60
```

**Profit Calculation**

Profit was calculated by subtracting the total cost from the revenue.

```python
df['Profit'] = df['Revenue'] - df['Cost']
```

**Profit Margin Calculation**

Profit margin was calculated as the percentage of profit relative to revenue.

```python
df['Profit_margine'] = (df['Profit'] / df['Revenue']) * 100
```

The generated features were displayed together for analysis.

```python
print(df[['Product', 'Price', 'Quantity', 'Revenue',
          'Cost', 'Cost_per_Unit', 'Profit',
          'Profit_margine']].head(10))
```

Additional calculations were performed to determine profit per unit.

```python
df['Profit_per_unit'] = df['profit'] / df['Quantity']
```

### 4. Categorical Feature Generation Using pd.cut()

Categorical features were generated by dividing numerical values into predefined ranges or bins.

The `pd.cut()` function was used to classify Revenue into three categories: Low, Medium, and High.

```python
range = [0, 500, 2000, 5000]

range_name = ['Low', 'Medium', 'High']

df['Revenue_Category'] = pd.cut(
    df['Revenue'],
    bins=range,
    labels=range_name
)

print(df['Revenue_Category'].head(10))

print(df['Revenue_Category'].value_counts())
```

The Revenue values were classified according to the defined intervals, and the frequency of each category was calculated.

### 5. Boolean and Flag Feature Generation Using np.where()

The `np.where()` function was used to generate a new categorical feature based on a condition.

Orders with a quantity greater than 3 were classified as Bulk Orders, while the remaining orders were classified as Regular Orders.

```python
df['Order_Type'] = np.where(
    df['Quantity'] > 3,
    "Bulk Order",
    "Regular Order"
)

print(df[['Product', 'Quantity', 'Order_Type']].head(10))

print(df['Order_Type'].value_counts())
```

This operation generated a new feature called `Order_Type` based on the Quantity column.

### 6. Multiple Conditional Feature Generation Using np.select()

The `np.select()` function was studied to generate categorical features using multiple conditions.

Unlike `np.where()`, which was used for two possible outcomes, `np.select()` allowed multiple conditions and corresponding choices.

The Price column was used to classify products into three categories:

- Budget: Price below 200
- Mid-Range: Price between 200 and 600
- Premium: Price above 600

```python
conditions = [
    df['Price'] < 200,
    (df['Price'] >= 200) & (df['Price'] <= 600),
    df['Price'] > 600
]

choices = ["Budget", "Mid-Range", "Premium"]

df['Product_category'] = np.select(
    conditions,
    choices,
    default="Unknown"
)

print(df[['Product', 'Price', 'Product_category']].head(20))
```

### 7. Comparison of Conditional Feature Generation Methods

The following functions were studied for generating categorical features:

- `np.where()` – Used when there are two possible outcomes based on a condition.
- `np.select()` – Used when multiple conditions and corresponding outcomes are required.
- `pd.cut()` – Used to divide numerical data into predefined intervals or bins.
